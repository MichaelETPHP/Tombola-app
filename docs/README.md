# Database Schema

Place your existing `schema.sql` file in this directory.

The SQL schema must be run against your Supabase PostgreSQL database before any of the three services (api, mobile-app, admin-app) will function correctly.

## How to apply

1. Open the [Supabase SQL Editor](https://supabase.com/dashboard/project/_/sql)
2. Paste the contents of `schema.sql`
3. Click **Run**

All tables, views, functions, and triggers will be created.
